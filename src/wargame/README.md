# Wargame Payloads - Level 1-10

## Cách lưu payload

Mỗi level lưu 2 file:
1. `level_0X_payload.txt` - Command/payload dùng để khai thác
2. `level_0X_notes.txt` - Ghi chú về lỗ hổng + cách làm

## Template

### level_0X_payload.txt
```
[Command / payload dùng để khai thác level X]
```

### level_0X_notes.txt
```
Level X - [Tên lỗ hổng]

Lỗ hổng: [Ghi chi tiết]
Cách khai thác: [Ghi cách làm]
Pass/Key: [Pass lấy được]
```
